WORKFLOW COMPLETED
----------------------------------------------------------------------------------------------------
1. Prepared a leakage-controlled modelling dataset.
2. Created 60% train / 20% validation / 20% untouched test splits.
3. Trained Logistic Regression baseline.
4. Trained Gradient Boosting, XGBoost and CatBoost candidates.
5. Compared Precision, Recall, F1, ROC-AUC, PR-AUC, Recall@Top10% and Lift.
6. Reviewed train-validation gaps for overfitting.
7. Optimised classification thresholds using validation data only.
8. Performed targeted XGBoost and CatBoost tuning.
9. Selected the final CatBoost model using validation evidence.
10. Froze the 0.49 threshold before opening the test set.
11. Evaluated the frozen configuration once on the untouched test set.

The test set was not used for model or threshold retuning.
