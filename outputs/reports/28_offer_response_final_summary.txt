CONCLUSION
----------------------------------------------------------------------------------------------------
Logistic Regression provided essentially no useful validation discrimination.
CatBoost improved only marginally above the no-skill benchmark and stopped at approximately the first boosting iteration.
The available subscriber attributes therefore do not provide sufficient out-of-sample signal for a useful offer-redemption propensity model.
Further hyperparameter tuning was intentionally not performed because it would risk fitting noise rather than producing a defensible model.

TEST SET DECISION
----------------------------------------------------------------------------------------------------
The dedicated offer-response test set was not opened because no validation-stage model demonstrated sufficient predictive usefulness.
This preserves the integrity of the test set and avoids using final-test performance to search for a better model.

DATA NEEDED FOR A STRONGER FUTURE SOLUTION
----------------------------------------------------------------------------------------------------
1. Subscriber-level offer or campaign ID.
2. Offer type and discount amount.
3. Offer assignment and redemption timestamps.
4. Channel used: app, SMS, call centre, etc.
5. Randomized control or holdout assignment.
6. Customer eligibility rules.
7. Historical offer-response behaviour.
8. Predictors measured strictly before offer assignment.
